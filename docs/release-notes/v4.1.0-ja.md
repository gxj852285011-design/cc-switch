# CC Switch v4.1.0 リリースノート

本バージョンでは、エンタープライズグレードの**ゼロトラスト中継クライアントスイート**（Zero-Trust Relay Client）および **NetBird WireGuard 出口セキュリティ監査アーキテクチャ**が正式に導入されました。AI Agent のマルチプロバイダー中継、ネットワークコンプライアンス、デバイス管理を包括的にサポートします。

---

## 🌟 主な新機能

### 1. ゼロトラスト中継クライアント（Relay Client）
Figma 3.0 海外版デザインシステムに基づき構築され、主要な 6 つの AI 開発ツール（Claude Code、Cursor、Codex、OpenCode、Gemini CLI、Oh My Pi）を完全にサポートします：
- **適応型 2 列ワークスペース**：FLIP スムーズ遷移アニメーションを採用し、カード展開時に自動的にコンパクトなレールに折りたたまれます。
- **ステートマシンとワンクリック設定**：各 CLI の詳細なヘルスチェック、ワンクリック設定書き込み、専用中継線の低遅延速度測定をサポート。

### 2. NetBird WireGuard 出口セキュリティ監査
- **デュアルゾーンインテリジェント監査**：「通常オフィスエリア」と「中継専用線安全エリア」の比較監査を提供し、出口 IP、地域、ISP、および遅延をリアルタイムで表示します。
- **DLP 情報漏洩防止監査**：送信トラフィックのルールマッチングエンジンを統合し、API キーや機密情報の誤送信を防止します。

### 3. エンタープライズデバイス管理センター（Device Center）
- **デバイスキーとリースの管理**：デバイスリストの一元管理、マルチティアクリップボード安全コピー機構、およびオンライン状態の切り替えを提供します。
