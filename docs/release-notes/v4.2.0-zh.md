# AI Agent Hub v4.2.0 发布说明

本版本是面向广大 **ToC 用户与团队办公** 的重大里程碑发布。全面完成了以原生桌面图形应用为核心的架构升级，彻底移除了易触发中国 IP 阻断的风险产品，并全面落地 ToC 桌面端主力阵容、语义解耦与丝滑交互动效。

---

## 🌟 核心更新亮点

### 1. 深度拥抱 ToC 桌面生态，全面转向桌面 GUI 阵容
根据 ToC 用户的真实使用习惯与无门槛办公需求，全面重塑 6 款主流 Agent / 客户端矩阵：
- **Cherry Studio 桌面端**：国内最火的开源多模型聚合桌面客户端，开箱即用，支持知识库与海外专线无缝对接。
- **ChatGPT 桌面端**：OpenAI 官方 macOS 原生桌面端，深度集成 Canvas 协同画布与语音交互，由纯净专线接管出口。
- **Chatbox 桌面端**：数百万 ToC 用户的国民级 AI 办公助手，原生支持一键注入中转加速专线。
- **Cursor 桌面端**：新一代全球顶尖 AI 智能工作台，支持代理与专线接入。
- **Kimi 桌面端**：月之暗面官方桌面客户端，超长上下文与深度文档问答，支持 DMG 静默安装，国内 IP 零门槛。
- **Hermes 深度推理智能体**：Nous Research 顶级开源自主智能体，支持 WireGuard 零信任直连专线与复杂多步自主推理。

### 2. 彻底移除 Claude 与 Google 产品，杜绝国内 IP 封号风险
- 为保障国内广大 ToC 用户资产与账号安全，全面移除所有带有 Claude 及 Google 标识的产品项。
- 网络出口安全中心全面重塑为 **「OpenAI 专线出口」** 与 **「海外主流 API 聚合专线」**，内置住宅级纯净 IP 分流，彻底阻断 IPv6 旁路泄露。

### 3. UI 交互规范闭环与语义严格解耦
- **右上角角标（Strict Install State）**：严格只反映是否安装（`已安装` / `未安装`），杜绝与配置状态混淆。
- **底部主按钮（Strict Config State）**：严格反映专线配置流转（`安装客户端` -> `配置专线` -> `● 已配置`）。已配置状态下点击直接一键唤醒拉起对应的本地 macOS 桌面应用。
- **左侧导航栏弹性位移动效**：采用 `framer-motion` 弹簧物理模型（`layoutId="sidebar-active-indicator"`），在「接入 / 设备管理 / 网络防封」间实现平滑平移动态。

### 4. 原生 macOS 独立桌面应用独立发布
- 彻底解耦老版外壳，作为原生独立应用 `AI Agent Hub.app` 运行，支持 Titlebar Overlay 沉浸式透明顶栏与原生红绿灯交通灯对齐。
- 提供便携式 DMG 镜像分发包，即拖即用。
