# CC Switch v4.1.0 Release Notes

This release officially introduces the enterprise-grade **Zero-Trust Relay Client Suite** and **NetBird WireGuard Egress Security Architecture**, delivering comprehensive multi-provider routing, compliance inspection, and device lifecycle management for AI developer agents.

---

## 🌟 Highlights

### 1. Zero-Trust Relay Client
Engineered according to the Figma 3.0 overseas design system, supporting 6 major AI development agents (Claude Code, Cursor, Codex, OpenCode, Gemini CLI, Oh My Pi):
- **Adaptive Two-Column Workspace**: Employs FLIP smooth transition animations that collapse cards into a compact rail when expanding agent drawers.
- **State Machine & One-Click Config**: Deep CLI health diagnosis, one-click configuration injection, and low-latency dedicated relay ping tests.

### 2. NetBird WireGuard Egress Security Audit
- **Dual-Zone Diagnostic Hub**: Comprehensive speed and route testing across Standard Office and Secure Relay zones, showing real-time egress IP, geolocation, ISP, and RTT.
- **DLP Data Leakage Prevention**: Integrated outbound traffic inspection engine intercepting exposed API keys and sensitive tokens before transmission.

### 3. Enterprise Device Management Hub
- **Device Lifecycle & Key Distribution**: Centralized inventory with multi-tier clipboard fallback and remote activation controls.
