# CC Switch v4.1.0 发布说明

本版本正式引入企业级**零信任中继客户端套件**（Zero-Trust Relay Client）与 **NetBird WireGuard 出口安全体检架构**，全面覆盖 AI Agent 终端的多供应商中转、网络合规及设备管理。

---

## 🌟 新增功能

### 1. 零信任中继客户端（Relay Client）
基于 Figma 3.0 海外版规范打造，全面支持 6 大主流 AI 开发工具（Claude Code、Cursor、Codex、OpenCode、Gemini CLI、Oh My Pi）：
- **双列自适应工作台**：采用 FLIP 无缝收拢与位移过渡动效，展开卡片时自动收拢为侧栏抽屉，确保多任务并行体验。
- **状态机与配置一键流转**：支持各 CLI 深度健康检查、一键配置写入与专属专线低延迟测速。

### 2. NetBird WireGuard 出口安全网络体检
- **双专区智能体检**：提供「普通办公区」与「中继专线安全区」对比体检，实时分析出口 IP、归属地、ISP 及延迟表现。
- **DLP 敏感数据防泄漏审计**：集成出站流量规则匹配引擎，防止 API 密钥、个人敏感凭据被误传或泄露。

### 3. 企业设备管理中心（Device Center）
- **多终端密钥与租约管理**：设备清单集中展示，提供双轨剪贴板安全复制机制及在线/离线平滑切换。
